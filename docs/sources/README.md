### Ratamestarikirja

SSL's course setter's handbook, which Lajisäännöt 10.32 requires course setting to follow. It is a website rather than a document: [sslkoulutus.fi/ratamestarikirja](https://sslkoulutus.fi/ratamestarikirja/etusivu/sisallys/). Each chapter is printed from the browser to PDF into `ratamestarikirja/`, named `<chapter> <title> – Ratamestarikirja.pdf` (185 chapters, printed 23 Oct 2026).

## Where things are

- **Course-planning principles:** IOF Rules 2026, Appendix 2. Competition formats and winning times: Appendix 6.
- **SSL course setting:** Lajisäännöt 10.3; course lengths and winning times 11.2; controls 11.4; control descriptions 12.2; sprint 18; SM winning times 19.4.
- **Ratamestarikirja for foot orienteering:** skills and leg types 1.1–1.2; fairness, safety, difficulty 1.3; long and middle distance 2.S.1–2.S.2; course planning as a whole 4.5.S; control sites 5.1; overprint 6.1–6.5; scales 6.8.1; colour skill levels 11. Chapters marked `.H`, `.P` and `.T` are for ski-O, MTB-O and trail-O.

## Missing

- **ISSprOM 2019-2** (sprint map specification). Not needed while we only support forest (ISOM) maps.
